# Python Media Catalogue

## About This Project
This project is an object-oriented Python media catalogue that stores and organizes movies and television series. It allows users to add media items, separate movies from TV series, and display the catalogue.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## Programming Concepts Demonstrated
- **Classes and Objects:** Created Movie, TVSeries, and MediaCatalogue classes.
- **Inheritance:** Used TVSeries as a child class of Movie.
- **Polymorphism:** Implemented different string representations for movies and TV series.
- **Custom Exceptions:** Created a MediaError exception for invalid media items.
- **Input Validation:** Checked media information before creating objects.
- **List Comprehensions:** Filtered movies and television series.
- **Exception Handling:** Used try and except blocks to handle errors.

## Features
- Stores movies and television series.
- Separates movies from TV series.
- Validates media information.
- Displays catalogue contents in an organized format.
- Handles invalid media items using a custom exception.
